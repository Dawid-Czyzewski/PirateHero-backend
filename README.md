# PirateHero Backend

Backend of the PirateHero game — a browser pirate-themed RPG. It exposes a REST API for character progression, combat, dungeons, economy, and social mechanics.

## Scope

- REST API for the PirateHero application
- JWT authentication with refresh tokens
- registration with email account activation
- character and progression module
- fights and arena system
- dungeons and bestiary
- ship and social mechanics
- shop, rewards, and in-game economy
- player ranking
- tests (PHPUnit)

## Technologies

- Symfony 7.2
- API Platform
- Doctrine ORM
- Lexik JWT Bundle
- Gesdinet JWT Refresh Token Bundle
- PHPUnit
